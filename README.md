# 📝 Todo Task Manager

Modern bir **Task Management Dashboard**.  
React + TypeScript kullanılarak geliştirilmiştir.

## 🚀 Özellikler

- Görev ekleme
- Görev düzenleme
- Görev silme
- Görev tamamlama
- Görev arama
- Filtreleme (All / Active / Completed)
- Akıllı sıralama (Smart Sort)
- Priority sistemi (High / Medium / Low)
- Deadline yönetimi
- Atanan kişi bilgisi
- Dashboard istatistikleri
- Progress bar
- Dark Mode
- Responsive tasarım

## 🧠 Smart Sorting

Görevler otomatik olarak şu kurala göre sıralanır:

1. Overdue
2. Today
3. Soon
4. On Track

Aynı grupta:

- High priority
- Medium priority
- Low priority

## 🛠️ Kullanılan Teknolojiler

- React
- TypeScript
- Bootstrap
- CSS
- LocalStorage
